External firewall rules (not stateful, DROP by default):
- Allows communication between client-robots and diagnostic server


Internal firewall rules (stateful, DROP by default):
DMZ network:
  - diagnostic-server sees db-internal, artifact-registry
  - diagnostic-server sees internal robots

Identity network:
  - DNS and LDAP visible by all
  - phpldapadmin only visible by IT

DEV/CI:
  - ci-server visible by internal robots

IT:
  - backup-log-server visible by all except users network
  - it-services visible by all
